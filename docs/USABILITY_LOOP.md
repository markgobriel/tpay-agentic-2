# Usability loop

Repeatedly complete the core flow as a novice: create a routine, understand when it is due, complete it, and find its history. Review visual hierarchy, content clarity, empty states, errors, keyboard paths, responsive behavior, and whether the flow feels proportionate to the job. Capture friction as an evidence-backed backlog item, then implement and compare the result. Local release readiness requires two consecutive clean audits after all critical flows pass.
